# Демонстрационные сайты мебельных компаний

Портфолио из 25 статических демонстрационных концепций: Гатчина и район, Воронеж. Это неофициальные сайты. Контакты и изображения сопровождаются источниками. Страницы не собирают и не передают заявки.

Каталог: index.html. Каждая компания: sites/<название>/index.html. Все пути относительные и подходят для GitHub Pages в подпапке проекта. Файл .nojekyll отключает обработку Jekyll.

Для публикации содержимое этой папки размещается в репозитории, затем включается GitHub Pages для корня основной ветки. Исследовательские заметки, доступы и рабочие данные в пакет не включены.
